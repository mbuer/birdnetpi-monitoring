# XGBoost vs Random Forest — v2 Horizon

## Date

2026-09-14

## Question

Does XGBoost improve BirdNET activity prediction compared with the current Random Forest model when both are evaluated using the corrected v2 prediction horizon?

## Context

The original live ML pipeline used the latest available hourly row as input. That could include an hour that was still in progress.

The corrected v2 pipeline uses only completed hourly input and predicts the next full future hour.

Example:

Run time: 23:10
Latest completed input: 22:00–23:00
Current hour already underway: 23:00–00:00
Prediction target: 00:00–01:00

Historical relationship:

feature hour T -> target T+2

This experiment therefore uses the same horizon as the corrected live pipeline.

## Dataset

Source:

PostgreSQL view: bird_activity_hourly

Experiment snapshot:

Raw hourly rows: 430
Valid v2 rows: 404
Walk-forward forecasts: 211

Dataset start:
2026-08-28 22:00

Dataset cutoff:
2026-09-14 17:00

The dataset is still small and covers only a short seasonal period.

Results should therefore be treated as experimental rather than as evidence of general bird behavior.

## Features

Both models use the same features:

hour_of_day
hours_from_sunrise
is_day
activity_index
activity_lag_1h
activity_lag_2h
activity_lag_3h
activity_lag_24h

Weather features are not used in this experiment.

## Validation Method

The experiment uses chronological walk-forward validation.

For each historical forecast:

1. only earlier rows are used for training
2. only target values that would already have been known at the simulated prediction time are available to the model
3. the model is retrained
4. one future target is predicted
5. the prediction is compared with the recorded activity

No random train/test shuffle is used.

Minimum initial training size:

192 rows

Total evaluated forecasts:

211

This method more closely reproduces the live v2 prediction process than the earlier rolling-window experiment.

## Baseline

Persistence is used as the baseline:

predicted target activity = latest completed activity

## Random Forest

Configuration:

RandomForestRegressor

n_estimators = 300
min_samples_leaf = 3
random_state = 42
n_jobs = -1

This is the current live model family.

## XGBoost

Version:

xgboost 3.4.1

Configuration:

XGBRegressor

n_estimators = 300
max_depth = 3
learning_rate = 0.03
subsample = 0.8
colsample_bytree = 0.8
objective = reg:squarederror
tree_method = hist

n_jobs = -1

These parameters were intentionally conservative.

No hyperparameter search was performed.

## Results

Model             MAE     RMSE
Persistence       6.123   10.463
Random Forest     4.498    7.146
XGBoost           4.460    7.127

XGBoost improved MAE over Random Forest by 0.85%.

The RMSE difference was also very small.

## Head-to-Head Forecast Wins

Random Forest wins: 126
XGBoost wins: 84
Ties: 1

Random Forest therefore produced the smaller error more often.

XGBoost nevertheless achieved slightly better aggregate MAE and RMSE, suggesting that some of its larger wins may have reduced overall error enough to offset the higher number of individual losses.

## Interpretation

XGBoost is clearly competitive with the current Random Forest model.

However, the difference is currently too small to justify replacing the live model.

Important observations:

- both ML models substantially outperform persistence
- XGBoost has slightly better aggregate MAE and RMSE
- Random Forest wins more individual forecasts
- the dataset is still small
- the improvement is only 0.85% in MAE
- no XGBoost hyperparameter tuning was performed

The result is therefore interesting but not decisive.

## Decision

Keep Random Forest as the current live champion.

Treat XGBoost as the first formal challenger.

Do not promote XGBoost based on this experiment alone.

## Next Experiments

Compare Random Forest and XGBoost separately for:

- daytime hours
- active bird hours
- high-activity / burst hours
- zero-activity hours

This should help determine where XGBoost gains its small aggregate advantage.

Further work may also include:

- feature ablation using the v2 horizon
- larger historical datasets
- carefully limited XGBoost parameter experiments
- weather-aware models
- champion/challenger evaluation based on live forward predictions

## Conclusion

XGBoost is worth keeping in the BirdNET ML project.

At the current dataset size it performs almost identically to Random Forest, with slightly lower aggregate error but fewer individual forecast wins.

The current evidence supports continued comparison rather than model replacement.
